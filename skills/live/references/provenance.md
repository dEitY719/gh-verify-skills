서로 다른 PR · 다른 화면 · 다른 결함 유형이었다. 어떤 항목이 어느 런에서 나왔고 무엇이
재현됐는지를 남겨 둔다 — 항목을 지우거나 완화하려 할 때 근거를 다시 찾지 않기 위함이다.
